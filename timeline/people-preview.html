统一优先 · 只在 3 处放「人物专属」元素

A · 风格对照：同一主题，两种卡型

左右各三张，一一对应（奥古斯都 / 查理曼加冕 / 拿破仑加冕）。白底、2:3、3px 势力色带、104px 插画窗、居中卡名、右上势力标签、hover 微浮起 —— 全部一致。

现有 时间线事件卡（41 张）

底部是单一年份；卡名是事件；插画是历史事件场景。

新增 人物卡（39 张）

底部是生卒区间；卡名是人名＋头衔；插画是人物肖像。

B · 三处「特别元素」

除这三处外，人物卡与时间线卡共用同一套 DOM 结构（.face / .fstrip / .art / .nm / .faction-tag）与同一套 CSS。

1
寿命徽章

插画窗左上角，与现有右上角的「势力标签」左右成对。显示周岁或约年，例如「75 岁」。这是唯一新增的独立 DOM 节点。

2
人名 ＋ 头衔

仍在原来的 .nm 里，仍是 flex:1 垂直居中，只是人名加粗、下面多一行 10.5px 灰色头衔（如「罗马皇帝 · Imperator」）。卡面垂直分布不变。

3
生卒区间

占据原来 .yr 的底部位置，同为一行小灰字；中间一段 30px 金线配两端圆点，把「一个点」变成「一段生命」。这也是后续生命带方案的视觉伏笔。

+
刻意不加的东西

不加新的势力颜色（文士并入现有「地方」色）、不加新字体、不加新边框材质、不改圆角与阴影、不改 hover / 选中动效、不改卡片 140×210 尺寸。

C · 39 张人物卡全览

按生年排序。A 类＝原文点名（21 位），B 类＝原文未点名、按史实推定（18 位）；轴外人物（希特勒 1889–1945）灰度弱化并单列。

D · 大卡详情：结构同样沿用

.bigcard 左图右信息（年代 / 中文 / 英文 / 讲解），下方「书中原句」中文块 ＋ 金色竖线英文原文块 —— 与时间线卡完全一致，只把顶部年份换成生卒区间、中文名换成人名。
